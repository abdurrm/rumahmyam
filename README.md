# RumahMYAM

Website profile RumahMYAM — layanan hosting UMKM, IT solusi, dan networking. Dibangun dengan [Elysia](https://elysiajs.com/) di atas Bun.

## Menjalankan

```bash
bun install
bun run dev      # development (auto-reload)
bun run start    # produksi
```

Server berjalan di http://localhost:3210

## Struktur

- `index.ts` — server Elysia (serving halaman + logo)
- `public/logo.png` — logo RumahMYAM
